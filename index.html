Research
The Latent Truth: Knowledge-Behavior Gap in Logical Deduction via Activation Steering
Harika Mahapatra, Vinayak Raj Urs
Preprint
code  /  project page

We study the gap between what language models internally represent and what they ultimately produce during generation. By probing intermediate representations, we show that models often encode correct logical structure but fail during decoding, and demonstrate that targeted activation steering can recover these failures without modifying model weights.

HRLS: Interpretable Temporal Prediction for Clinical Decision Support
Harika Mahapatra
NeurIPS WiML Workshop · IEEE Global AI Summit
code  /  project page

We develop a hybrid framework that combines interpretable models with temporal deep learning through a residual formulation. By structuring the model as a transparent baseline corrected by a learned temporal component, we preserve interpretability while capturing sequential patterns in complex prediction tasks.

Statistically-Grounded Attention for Alzheimer's Detection
Harika Mahapatra, Dr. A. V. Sriharsha
AIML-CEB @ AJCAI · IEEE Global AI Summit
code  /  project page

We propose a statistically grounded approach to multimodal learning, replacing learned attention with weights derived from data reliability. This yields more stable and interpretable predictions across heterogeneous inputs, while maintaining strong performance in complex settings.
